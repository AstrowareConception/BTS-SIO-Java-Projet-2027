# 00 — Démarrage

## Avant de coder
1. Lire les trois sujets.
2. Choisir un sujet.
3. Réserver 3 modules principaux + 2 secondaires.
4. Créer le dépôt personnel.
5. Copier/adopter le starter.
6. Reformuler le besoin.
7. Concevoir les principaux écrans JavaFX et Web.
8. Modéliser les données et l'API.
9. Construire le backlog.

## Livrables du lundi matin
- cahier des charges personnalisé ;
- choix de modules validé ;
- cas d'usage ;
- modèle de données ;
- premières URI REST ;
- maquettes du client JavaFX ;
- maquettes de l'administration Web ;
- dépôt initialisé.

## Définition de terminé
Une fonctionnalité est terminée si :
- le serveur la gère ;
- l'API respecte son contrat ;
- les droits sont contrôlés côté serveur ;
- le client gère succès ET erreurs ;
- les tests pertinents existent ;
- la documentation est à jour ;
- elle est démontrable.
