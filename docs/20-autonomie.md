# 20 — Guide d'autonomie

## Avant de demander « je fais quoi ? »
1. regarder le jalon du jour ;
2. regarder le backlog ;
3. prendre le must-have le plus important non terminé ;
4. vérifier la checklist.

## Blocage technique
Procédure :
1. reproduire ;
2. lire le statut HTTP ;
3. lire le log serveur ;
4. lire le log/exception client ;
5. réduire le problème ;
6. consulter la doc officielle ;
7. tester une hypothèse.

## Bonne demande d'aide
```text
Je veux :
J'obtiens :
J'attends :
Endpoint :
Statut HTTP :
Exception serveur :
Exception JavaFX :
Tests déjà faits :
```

## Si vous êtes en avance
1. renforcer tests ;
2. terminer modules secondaires ;
3. améliorer UX JavaFX ;
4. durcir sécurité ;
5. bonus.

## Si vous êtes en retard
Supprimez les bonus et le cosmétique avant de sacrifier :
- architecture ;
- REST ;
- sécurité ;
- modules principaux ;
- tests ;
- documentation.
