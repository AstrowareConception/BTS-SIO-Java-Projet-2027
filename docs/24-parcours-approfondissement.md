## Règle
Un approfondissement doit produire au moins une trace :
- issue ;
- ADR ;
- test ;
- rapport ;
- capture ;
- amélioration CI ;
- documentation.

Sinon vous aurez appris quelque chose, mais vous aurez peu de preuve exploitable.
