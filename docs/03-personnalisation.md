# 03 — Personnalisation

Chaque sujet possède un socle obligatoire et **10 modules**.

## Choix
- **3 modules principaux** : contractuels, terminés/testés/démontrables.
- **2 modules secondaires** : backlog secondaire.

## Unicité
Deux étudiants ayant le même sujet ne peuvent pas partager le même triplet principal.

## Contraintes du triplet
Il doit contenir :
- au moins un impact modèle/workflow ;
- au moins un impact JavaFX ;
- au moins un impact serveur significatif.

## Preuves
Pour chaque module principal :
- besoin ;
- modèle impacté ;
- endpoints ;
- classes ;
- écrans ;
- tests ;
- captures ;
- commits.
