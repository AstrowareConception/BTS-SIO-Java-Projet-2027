# 11 — Administration Web

Un front Web d'administration est obligatoire.

## Technologie libre
- Thymeleaf ;
- HTML/JS ;
- Vue ;
- React ;
- autre solution justifiable.

Le starter utilise **Thymeleaf** pour fournir une voie simple sans imposer un nouveau framework JS.

## Fonctions typiques
- tableau de bord ;
- utilisateurs ;
- médias ;
- catégories/tags ;
- upload ;
- publication/archivage ;
- droits ;
- statistiques selon modules.

## Contrainte
L'administration Web utilise les mêmes services métier : elle ne doit pas contourner les règles applicatives.
