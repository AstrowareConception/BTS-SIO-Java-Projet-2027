# Évolutions à attribuer mercredi

## Principe
Attribuer un module non sélectionné ou une variante qui oblige à analyser l'impact.

## MediaVault
- MV-E1 : ajouter un statut de validation en préservant les données existantes.
- MV-E2 : nouvelle version de fichier avec URI métier stable.
- MV-E3 : date d'expiration de droits + recherche + JavaFX.
- MV-E4 : quota par contributeur.

## EduMedia
- ED-E1 : association à plusieurs compétences.
- ED-E2 : ressource obsolète + remplaçante.
- ED-E3 : progression utilisateur.
- ED-E4 : niveau d'accès par formation.

## StudioFlow
- ST-E1 : expiration de licence.
- ST-E2 : cue points.
- ST-E3 : historique de diffusion.
- ST-E4 : plusieurs versions.

## Variante avancée
Faire évoluer le serveur **sans rupture du contrat existant consommé par JavaFX**.
