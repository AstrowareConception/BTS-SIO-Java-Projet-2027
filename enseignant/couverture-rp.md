# Complémentarité avec la RP Web PHP/Slim

Cette semaine Java ne cherche pas à refaire le projet de novembre.

| Axe | RP Web | RP Java |
|---|---|---|
| Navigateur Web | fort | admin secondaire |
| Client lourd | absent | central |
| Framework serveur | Slim | Spring Boot |
| Accès données | Medoo/PDO | JPA/Hibernate |
| POO | modérée | forte |
| REST exposition | oui | centrale |
| REST consommation | limitée | centrale JavaFX |
| Plusieurs clients | limitée | JavaFX + Web |
| Fichiers multimédias | possible | obligatoire |
| Player | non | oui |
| OpenAPI | bonus | obligatoire |
| Sécurité | oui | centralisée multi-client |
| CI/tests | oui | renforcés |
| Packaging desktop | non | oui |

Objectif : que les deux réalisations réunies donnent un ensemble de preuves très large et cohérent, sans multiplier artificiellement les technologies.
